This folder contains the ontology and manuscript sources for the Æther-Flow research program.

The scientific goal of the project is to derive general relativity (GR) from the Æther-Flow ontology. The research is carried out with **Sys4AI**, an agentic research system that coordinates AI agents, roles, skills, research tasks, and verification processes. Sys4AI provides the research infrastructure; the ontology provides the scientific starting point.

The comprehensive TeX source and its compiled PDF are the **canonical final versions** of the ontology manuscript. The individual manuscripts remain available in `aether_flow_manuscript-sets/` for focused reading, editing, and reference.

## File map

| --- | --- |
| `aether_flow_manuscript-sets/` | Individual manuscript PDFs, TeX sources, and shared LaTeX support files. |
